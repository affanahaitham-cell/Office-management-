Executive & Commerce Notes Hub

To run:
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. For best results, run a local static server from this folder (for example: python -m http.server 8000) and open http://localhost:8000.

Included:
- Responsive Arabic-first website with English study terms.
- Five original course PDFs and extracted text copies.
- Chapter navigation, summaries, bilingual glossary, interactive sample quizzes, search, local demo sign-in, and usage policy.

Important limitations:
- This is a working static website package, not a deployed public website.
- Sign-in is a local demo using browser storage; it is NOT secure production authentication and has no shared user database.
- Quizzes and bilingual summaries are starter content, not a complete translation or exhaustive question bank for every page. The original PDFs are included intact.
- To publish online with secure accounts, progress sync, and AI tutoring, connect a hosting provider, backend/database, authentication, and an AI API.
